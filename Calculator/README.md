# 🧮 Menu-Driven Calculator in C

A simple menu-driven calculator developed using the C programming language. It performs basic arithmetic operations based on user input.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- `%` Modulus
- 🔄 Repeated operations using a loop
- 🚪 Exit option
  

## 🛠️ Concepts Used

- Variables and Data Types
- Arrays
- User Input and Output
- `while` Loop
- `if-else` Statements
- Arithmetic Operators
-  `return`

## 📂 Files

| File | Description |
|---|---|
| `calculator.c` | Main C source code |
| `README.md` | Project documentation |

## ▶️ How to Run

**1. Compile the program**

```bash
gcc calculator.c -o calculator
```

**2. Execute the program**

```bash
./calculator
```

On Windows:

```bash
calculator.exe
```

## 💡 Learning Objective

To understand how loops, conditional statements, user input, and arithmetic operators work together to create an interactive menu-driven application.
