# 🏦 ATM Banking System in C

A beginner-friendly, menu-driven ATM simulation developed using the C programming language.

This program allows users to perform basic banking operations such as withdrawing money, depositing money, and checking their current account balance.

## ✨ Features

- 💰 Deposit Money
- 💸 Withdraw Money
- 🏦 Check Current Balance
- ⚠️ Invalid Transaction Handling
- 🔄 Continuous Menu Operations
- 🚪 Exit Option

## 🛠️ Concepts Used

- Variables and Data Types
- `for` Loop
- `if-else` Statements
- Arithmetic Operators
- Logical Operators
- User Input and Output
  

## 💵 Initial Balance

int balance = 5000;

## ▶️ How to Run

**Compile:**

```bash
gcc bank.c -o atm
```

**Run on Linux/macOS:**

```bash
./bank
```

**Run on Windows:**

```bash
bank.exe
```

To understand how variables, loops, conditional statements, and arithmetic operations can be combined to simulate a simple banking system.
